# Tuval Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the drawing-engine implementation and independent spec and quality reviews. The controller integrates the interface, verifies production behavior, and publishes the reviewed result. Steps use checkbox syntax for tracking.

**Goal:** Preserve every existing drawing feature while fixing the toolbar, freehand drawing, and touch behavior; publish a maintained public repository at tuvall.netlify.app.

**Architecture:** Browser-native modules with Vite. A document canvas retains artwork dimensions across viewport changes; a display canvas maps pointer coordinates to the document. A preview layer makes translucent strokes uniform. History and persistence are independent of UI controls.

**Tech Stack:** JavaScript, Canvas 2D, Pointer Events, IndexedDB, Vite, Node test runner, Playwright, axe.

## Task 2: Drawing engine

Files: `src/engine/canvas.js`, `src/engine/history.js`, `src/engine/input.js`, `src/engine/stroke.js`, `src/engine/fill.js`, `src/engine/color.js`, `tests/unit/*.test.js`.

- [ ] Use this public engine contract, keeping UI out of engine modules:

```js
const engine = new DrawingEngine(canvas, {
  onChange: () => saveDrawing(),
  onHistoryChange: ({canUndo, canRedo}) => updateHistoryButtons(),
  onTextRequest: ({x, y, clientX, clientY}) => openTextEditor(),
});
engine.setOptions({tool: 'pen', color: '#202923', alpha: 1, size: 5, pressure: true, touchDrawing: true});
engine.undo(); engine.redo(); engine.clear();
engine.addText('Hello', {x: 50, y: 50});
await engine.toBlob();
await engine.loadBlob(blob);
```

- [ ] Add failing tests for quadratic curve generation, final endpoints, color round trips and invalid input, flood-fill boundaries, and branching history.
- [ ] Run `npm test` and confirm the failures before implementing the helpers.
- [ ] Implement all nine tools with isolated drawing state; midpoint smoothing and pointer capture; ignore additional pointers; handle cancellation; render pressure and coalesced samples; preserve document content on resize.
- [ ] Run `npm test`; all tests must pass.
